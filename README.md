# Java Password checker
A command line program that allows the user to create a passowrd and check against requiremtns.
Created in 2025 as a quick project.

## Features
- Checks against requirements
- allows users to retry multiple times until the program is satisfied with the input
- Uses list/array list to output the requirements the user has not met yet.

## Tech Stack
- Java
- Regex (`java.util.regex.Pattern`) 
- List/ArrayList (`java.util.List`) (`java.util.ArrayList`)
- Scanner (`java.util.Scanner`)
